## Core Rules (If/Then)

### Rule 1: Task Decomposition
**IF**: Task estimated > 30 minutes
**THEN**: Must break into 3-5 micro-tasks (5-10 minutes each)
**EXAMPLE**: 
- ❌ "Design complete framework" (too large)
- ✅ "1. Create decomposition rule (5 min)"
- ✅ "2. Design consequence system (5 min)"
- ✅ "3. Test with one task (5 min)"

### Rule 2: ByteRover Habit
**IF**: Starting any task
**THEN**: Must attempt ByteRover query first
**SUCCESS DEFINITION**: Attempt made (even if authentication needed)
**DOCUMENTATION**: Log attempt in progress tracker
**STREAK GOAL**: 21 days of consistent attempts

### Rule 3: Analysis Time Limit
**IF**: Planning/analysis > 15 minutes without action
**THEN**: Must execute one micro-action immediately
**CONSEQUENCE**: If not done, document failure in memory file
**RESET**: Start with simplest possible 5-minute task

### Rule 4: Accountability Checks
**IF**: Hourly checkpoint reached (every 30 minutes)
**THEN**: Must update progress tracker with:
  1. What was accomplished since last check
  2. What's next (specific micro-action)
  3. ByteRover usage status
**CONSEQUENCE**: Missed check → extra accountability check

### Rule 5: Consequence System
**LEVEL 1 (Warning)**:
- **Trigger**: Missed micro-action deadline
- **Action**: Document in memory file with reason
- **Example**: "Missed 1:30 PM task - reason: over-analysis"

**LEVEL 2 (Penalty)**:
- **Trigger**: Skipped ByteRover attempt
- **Action**: Extra accountability check immediately
- **Example**: "Skipped ByteRover → do check now"

**LEVEL 3 (Restriction)**:
- **Trigger**: Analysis > 30 minutes without action
- **Action**: Can only work on micro-tasks next hour
- **Example**: "Over-analysis → only 5-min tasks next hour"

**LEVEL 4 (Reset)**:
- **Trigger**: Multiple failures in one session
- **Action**: Start over with simplest possible task
- **Example**: "Reset → update progress tracker (5 min)"
