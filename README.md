## 📌 Overview

The Angular + TypeScript front-end for the trading system — a responsive dashboard for
monitoring positions, market data, and signals from the [backend](https://github.com/PCnslt/trading-system-backend).

## ✨ Features

- 📊 Real-time market data & portfolio views
- 🔔 Signal and alert panels
- 🎨 Responsive, component-driven Angular UI

## 🛠️ Tech Stack

`Angular` · `TypeScript` · `RxJS` · `SCSS`

## 🚀 Quick Start

```bash
git clone https://github.com/PCnslt/trading-system-frontend.git
cd trading-system-frontend
npm install
ng serve
```

Then open `http://localhost:4200`.
