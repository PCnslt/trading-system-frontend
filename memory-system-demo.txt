## 🔄 How It Works

### 1. Multi-Layer Architecture
- **Hot RAM**: Immediate working memory (session context)
- **Warm Store**: Recent conversations and learnings (7 days)
- **Cold Store**: Important long-term knowledge
- **Archive**: Complete historical record

### 2. Auto-Pruning System
Each memory item gets scores:
- **Recency**: How recent? (exponential decay over 24h)
- **Relevance**: How related to current topic?
- **Importance**: User-assigned or calculated importance
- **Access**: How often retrieved?

Items with low composite scores are automatically:
- Moved to appropriate storage tier
- Archived if old but potentially useful
- Removed if no longer relevant

### 3. Self-Evolution
The system learns from usage patterns:
- Adjusts pruning thresholds based on effectiveness
- Optimizes storage allocation
- Improves retrieval accuracy over time
- Generates weekly evolution reports
